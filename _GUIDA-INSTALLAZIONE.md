# Terminale — PWA

App di studio offline per imparare Linux, bash, reti, strumenti e Python.

## Installare sul telefono (GitHub Pages)
1. Crea un repository su GitHub chiamato **terminale**
2. Carica TUTTI i file di questa cartella (index.html, manifest.webmanifest, sw.js, icon.svg) nella radice del repo
3. Vai in Settings -> Pages -> Source: "Deploy from a branch" -> branch main, cartella / (root)
4. Apri l'URL che GitHub ti dà (tipo https://tuonome.github.io/terminale/)
5. Sul telefono: menu del browser -> "Aggiungi a Home". Ora funziona offline.

Dopo la prima apertura online, l'app resta disponibile senza connessione.
